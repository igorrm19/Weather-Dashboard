# 🌤️ Duo Weather Dashboard

Um painel de previsão do tempo moderno, limpo e responsivo, desenvolvido com JavaScript puro e a API OpenWeatherMap.

![Preview do Projeto](public/Screenshot%20from%202026-01-09%2009-21-14.png)

## 🚀 Funcionalidades

- **📍 Geolocalização:** Detecta automaticamente sua localização para exibir o clima local ao abrir o app.
- **🔍 Busca por Cidade:** Pesquise o clima de qualquer cidade do mundo.
- **📅 Previsão de 5 Dias:** Visualize a previsão detalhada para os próximos dias, incluindo temperatura e umidade.
- **📜 Histórico de Busca:** Acesso rápido às últimas cidades pesquisadas (salvo localmente).
- **🎨 Design Dinâmico:** O plano de fundo do aplicativo muda de acordo com as condições climáticas (Ensolarado, Nublado, Chuvoso).
- **📱 Responsividade:** Layout otimizado para dispositivos móveis e desktop.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica.
- **CSS3:** Layout com Flexbox e Grid, design moderno com gradientes e sombras suaves.
- **JavaScript (ES6+):** Manipulação de DOM, Fetch API para consumo de dados e geolocalização.
- **API OpenWeatherMap:** Fonte de dados climáticos em tempo real.

## 📦 Como Executar o Projeto

1. Clone este repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` diretamente no seu navegador ou utilize uma extensão como o *Live Server* no VS Code.
3. Certifique-se de permitir o acesso à localização se desejar ver o clima da sua região automaticamente.
